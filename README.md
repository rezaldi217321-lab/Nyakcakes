# NYAK.CAKES — Premium Bakery

Website katalog dan pemesanan untuk Bingkang Aceh, Fudgy Brownies, Bolu Lumer, dan pilihan bakery lainnya.

## Menjalankan secara lokal
1. Install Node.js.
2. Jalankan `npm install`.
3. Jalankan `npm run dev`.

## Deploy ke Cloudflare Pages
- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`

## Catatan
- Harga awal belum diisi. Admin dapat mengatur harga dari tombol pengaturan di website.
- Password demo admin: `nyakcakes` (ganti sebelum website dipakai publik).
- Nomor WhatsApp admin dapat diatur dari pengaturan toko.
- Pengaturan admin saat ini tersimpan di browser (localStorage), belum memakai database/server.
- Gambar menu asli dan logo merek disertakan dalam `public/images`.
